## 📖 Project Overview

The **Inventory and Data Management System** is a robust, database-driven RESTful Backend API developed using Node.js, Express.js, MongoDB, and Mongoose.

This system is designed to manage a store or warehouse's inventory and product catalogue efficiently. It provides features such as field-level schema validation, complete CRUD operations, query-string-based filtering, sorting, pagination, safe stock increment and decrement operations, and advanced MongoDB aggregation reports.

The project demonstrates the practical implementation of backend development concepts, database management, API development, and data validation.

---

## ✨ Key Features

- **Product Management:** Create, retrieve, update, and delete products.
- **Schema Validation:** Apply field-level validation using Mongoose.
- **Filtering:** Search and filter products using query parameters.
- **Sorting:** Sort products based on selected fields.
- **Pagination:** Retrieve products in organized pages.
- **Stock Management:** Safely increment and decrement product stock.
- **Low-Stock Alerts:** Identify products with low inventory levels.
- **Inventory Summary:** Generate category-wise inventory reports using MongoDB aggregation.
- **Error Handling:** Manage application errors through centralized error-handling middleware.
